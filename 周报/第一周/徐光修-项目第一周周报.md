**二、 本周完成工作**

*   **目标达成情况：**
    1. Agent 图引擎核心开发：已完成 100%
    2. 工具系统完整链路搭建：已完成 100%
    3. 双协议 API 层开发：已完成 100%
    4. RAG 基础能力建设：已完成 100%
    5. 统一检索编排服务：已完成 100%

*   **具体完成任务列表：**
    *   **Agent 图引擎（`agent_core/`）：** 构建了 7 节点 LangGraph 状态机（planner → model_decision → tool_call → observation → compress → safety），支持流式/非流式双入口、多线程安全执行引擎、6 种事件类型推送、客户端断开自动中断。
    *   **工具系统（`tools/`）：** 实现三层分离架构（ToolRegistry → ToolExecutor → builtin.py），完成 20+ 个内置工具（通用工具 9 个、记忆工具 2 个、知识库工具 3 个、文件管理 7 个、状态管理 1 个、联网搜索 1 个），提供线程级运行时上下文和 6 种回调通道。
    *   **双协议 API 层（`api/`）：** 同时提供 FastAPI REST（12+ 端点，涵盖 health/agent/session/knowledge/settings）和 gRPC 协议接口，SSE 端点透传 AgentCore 事件流。
    *   **RAG 基础能力（`services/memory/rag/`）：** 完成 Embedding 向量生成（SentenceTransformer 全局单例 + 延迟加载 + 向量归一化）、文本重叠切片（段落优先策略 + 边界异常处理）、CrossEncoder 精排（sigmoid 归一化 + 回退策略）、混合检索（英文 token + 中文 n-gram 关键词抽取 + 双路去重合并）、知识库灌库引擎（哈希锁去重 + 全量溯源路径 + 双写 SQLite/ChromaDB）、多模态文档清洗器（覆盖 10 种格式：JSON/JSONL/CSV/TSV/HTML/XML/DOCX/XLSX/PPTX/PDF）。
    *   **统一检索编排服务（`retrieval_service.py`）：** 编排完整召回流水线（Embedding → 双路径向量召回 → 并行关键词召回 → 双路合并 → CrossEncoder 精排 → 时效性/权威性加权 → 阈值过滤），同时服务于长期记忆检索和知识库检索双场景，提供 ReRank 前后快照调试接口。
    *   **运维脚本（`scripts/`）：** 实现模型下载（完整性校验 + snapshot_download）、frontmatter 灌库 CLI（一键全流程 + 全量统计返回）。
    *   **数据 Schema 与配置：** 定义 Message/Session/LongTermMemorySpec 等核心 DTO，实现 AgentConfig 覆盖 model/storage/memory/server/mcp/safety/constants 全量配置节。

**四、 遇到的问题与困难**

*   **技术问题：**
    *   Windows 环境下 gRPC IPv6 wildcard（`[::]`）绑定异常
    *   **已尝试的解决方案：** 添加自动降级逻辑，检测到 `[::]` 绑定失败时自动回退到 `0.0.0.0`
    *   **需要帮助或待解决：** 无
*   **非技术问题：**
    *   模块间依赖协调：工具系统需要前置定义好 ToolRegistry 接口，RAG 模块需要前置确定数据模型
    *   **已采取的措施：** 先定义接口协议和数据结构（frontmatter_document.py / LongTermMemorySpec），再按依赖序开发，保证层间无循环依赖
