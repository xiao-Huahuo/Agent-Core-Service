# 2026-08-25 变更记录

## 图书馆三级响应式布局

- 图书馆改为依据工作区卡片实际宽度切换桌面、平板和移动布局。
- 平板端操作按钮统一置于第二行；移动端按“导航与查找 / 路径 / 操作按钮”重排为三行，详情栏改为覆盖式抽屉。
- 桌面布局保持不变；界面截图由用户后续人工验收。

## TopCommandBar 移动端精简

- TopCommandBar 跟随主工作区卡片实际宽度进入移动状态。
- 移动状态保留完整品牌与库名、Agent、Git、Todo、搜索以及窗口控制，其余右侧操作隐藏。

## 文件树移动端浮层

- 移动布局中的文件树改为带阴影的左侧覆盖式侧栏，不再压缩编辑区。
- 浮层内新增折叠按钮；折叠后在编辑区文件标签栏左侧显示同款展开按钮，并复用原有位移与透明度动效。
- 编辑区移动端隐藏单选项文件类型，保存按钮固定到标签栏右上角，多模式 Toggle 与展开按钮左对齐。
- 移动端普通文件打开后自动折叠文件树浮层；文件夹展开和多选不会触发折叠。

## 组件库移动端侧边栏

- 组件库标签侧边栏在移动端改为左侧阴影浮层。
- 侧边栏与标题栏增加同款折叠/展开按钮，并复用文件树的透明度与左移动效。

## 密码库移动端侧边栏

- 密码库筛选侧边栏在移动端改为左侧阴影浮层。
- 筛选侧边栏与密码库标题栏增加同款折叠/展开按钮和左移动效。
- 密码库在主区域 `860px` 以下直接进入浮层侧边栏，跳过旧横向筛选条。

## 智能表格响应式顶栏

- 智能表格复用原有工具栏控件并按主操作、目录、二级操作三行重排，不维护第二套移动工具栏。
- 主区域 `1040px` 以下使用固定文字的切换、筛选和其他按钮；筛选按钮动画展开标签与星级筛选行。

## 智能表格移动端布局

- 删除残留的基于视口的 `@media (max-width: 760px)` 死代码，三级断点统一走容器查询（`1040px` / `640px`），与图书馆页一致。
- 主区域 `640px` 以下新增移动端断点：页面骨架紧凑化，首行缩为三列并隐藏删除表格按钮，危险操作移入"其他"菜单，避免菜单重复项。
- "其他"菜单 Teleport 到 body，容器查询无法命中其内部项，故以 ResizeObserver 感知根容器宽度，仅移动端注入删除菜单项。
- 表格主体移动端固定左侧行号列横向滚动；文献列（原本即为 sticky 左列）在行号列右侧让位 `left: 32px`，普通表无行号/文献列，规则自然不命中。
- 底部信息条移动端精简，隐藏导出文件名；截图存于 `docs/screenshots/smart-forms-{desktop,tablet,mobile}.png` 及真实窄视口图，布局要点经 Playwright 量化断言验证，最终效果由用户人工验收。

## LaTeX 编辑、编译与分屏预览

- `.tex` 进入 `Code / Preview / Split` 编辑管线并注册 LaTeX 语法高亮；默认使用 `latexmk + pdfLaTeX`，支持 `%!TeX program` 自动切换 XeLaTeX/LuaLaTeX、`%!TeX root` 和 `-g` 强制重建，默认禁用 unrestricted shell escape。
- 编译 PDF、AUX、LOG 与 SyncTeX 写入知识库 `.mw/latex`，PDF 继续复用现有 `PdfPreview`；错误面板显示源码行号和完整日志。
- 新增系统/托管编译器检测以及当前用户范围的 MiKTeX Setup Utility 下载、SHA-256 校验、安装、取消、按需宏包配置和托管卸载；REST 与 gRPC 使用同一服务。
- 存储管理新增 LaTeX 运行时、MiKTeX 核心与宏包、下载仓库、临时文件和知识库编译缓存；仅下载仓库、临时文件和编译缓存进入精确清理白名单。
- `.tex` 加入知识库支持后缀，并明确按文本结构化，避免误入多模态清洗器。
- 修复文件刚打开就切换 Split 时异步加载未完成、空内容被保存覆盖的风险。
- 修复固定 XeLaTeX 导致 `pdftex` 模板在 VS Code 成功而 MetaWeave 失败的问题；latexmk 摘要不足时会追加真实 `.log` 并提取源码行错误。
- TeX 编译 PDF 的预览顶栏新增下载按钮，复用原始文件接口导出同名 PDF；普通知识库 PDF 顶栏保持不变。
- README 增加面向用户的 LaTeX 安装、编译、分屏预览、错误处理和存储说明，并修正知识库数量及 `.mw` 可见性描述。
- 真实系统 MiKTeX 与 Vite 代理完成桌面、平板、移动三级 Playwright 冒烟；截图为 `docs/screenshots/latex-{desktop,tablet,mobile,storage}.png`。
