## 修复子 Agent 完成提示重复与 DeepSeek thinking 续轮 400

- 子 Agent 管理器新增按 `run_id + Turn` 的原子完成唤醒领取；多窗口或多个 store 同时观察终态时只有一个观察者能唤醒主 Agent，DSH 追问的新 Turn 可重新领取。

- DeepSeek 适配器支持 `provider/deepseek-*` 等命名空间模型，并在 assistant tool-call → tool result 的下一次请求中回传 `reasoning_content`。
- 新增管理器并发回归、前端 store/API 回归与实际 Agent 页面 Playwright 冒烟；界面验证两个创建事件对应恰好两个完成提示和两个 claim。
