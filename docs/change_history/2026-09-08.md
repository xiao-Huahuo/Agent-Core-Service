# 2026-09-08

## 新增扫描器工作区

- 新增持久化扫描记录、Alembic 迁移、受控后台解析任务与 `/scanner` REST API。上传文件统一隔离到当前知识库 `.mw/scan/<scan_id>/`，任务状态、OCR/no OCR 可编辑草稿和收藏均由 SQLite 持久化。
- 复用现有多模态灌库链的 Markdown 投影阶段，在 embedding 前停止；OCR 开启时生成纯文字 OCR 结果和保留本地图片资产的 no OCR 结果，网页入口包含公共地址校验、重定向校验、大小限制及 HTML-to-Markdown 转换。
- 新增 MinerU 式扫描器页面、最近解析栏、拖放/系统文件选择、网页链接、OCR 设置、像素进度、7 个真实示例、双栏原文件/Markdown 编辑区、知识库保存、系统另存为导出和全文复制。
- 收藏页新增“扫描器”子页，复用扫描历史卡片；删除历史同步删除收藏记录与隔离的受管文件。
- Electron 新增受限的系统另存为桥接；Vite 新增 `/scanner` 开发代理；存储管理登记 `.mw/scan`。
