- 本地 Qwen 接入现有模型下载、加载、状态、真实字节进度和存储路径管理，并扩展 REST、gRPC DTO 与前端类型。
- 修复本地 Qwen 下载在后端重启后长期停留于旧百分比的问题：从 Hugging Face `.incomplete` 断点文件恢复真实已下载字节，启动时自动续传，并避免磁盘检测覆盖活动下载状态。
- 修复模型管理页面仅在本页主动发起下载时才轮询的问题；页面首次读取到下载或加载状态时会自动开始刷新进度，任务结束后自动停止。
- 修复 Hugging Face 将 Qwen 单分片权重命名为 `model.safetensors-00001-of-00001.safetensors` 时被误判为模型缺失的问题；已下载权重可直接识别，无需重下。
- 修复本地 Qwen 加载所需运行时不完整及消息格式不兼容的问题：固定 CPU `torch 2.11.0`/`torchvision 0.26.0`、Transformers 5.2 与 sentence-transformers 6.0 兼容组合，并让纯文本消息使用 Qwen3.5 多模态内容块格式；PyInstaller 不再排除 Torchvision。
- Agent 输入框右下角改为显示 `effective_model_name`；因此未配置远程大模型时会明确显示实际回退的 `Qwen/Qwen3.5-2B`，保存设置后也会立即刷新。
- LLM 配置页新增“当前生效”大小模型摘要，分别显示后端解析后的实际模型名，并区分本地回退、远程大模型复用和大小模型独立配置状态；未保存的编辑草稿不会冒充当前运行配置。
- 大模型和小模型配置分别增加复用存储管理删除样式的清空按钮；清空先进入编辑态、保存后生效，并移除小模型标题右侧的规则说明。
- 直接上传图片在 PaddleOCR 之后调用本地 Qwen，合并文字与视觉语义到会话附件上下文；新增 Agent“识图”工具按需重新分析当前会话图片。
