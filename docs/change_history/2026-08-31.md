- thinking 与正文 token 不再重复发送动态 backend elapsed metadata；前端同时兼容过滤旧协议耗时，流式草稿固定为 20Hz 合并提交，并移除空 tool_calls/trace 的逐 token 响应式赋值。

- Markdown 改为追加式稳定块扫描：每批只解析和净化新增稳定片段，活跃尾部单独重绘，终态全量校正；Thinking 折叠态不再挂载全文或读取布局宽度，摘要增量维护，动画改用 transform 合成层。
- 新增正式后端 token metadata 契约、20,000 字窗口同步压力、稳定 Markdown DOM、Thinking 挂载行为与重复/乱序事件回归。
- 真实界面注入 30,000 个 thinking 与 3,000 个正文 SSE 事件：全文无丢失、按钮响应 44–66ms、最长 long task 50–51ms、无页面异常；生产构建通过，验收记录见 `docs/acceptance/agent_stream_performance.md`。
