## 四、边界场景测试（5 个极端输入场景）

### 场景 1: 空的上下文窗口
- **测试**: `test_context_builder_drops_incomplete_assistant_tool_call_history`
- **描述**: 历史中仅有孤立的 assistant tool_calls（关联的 ToolMessage 因窗口裁剪丢失）
- **验证**: ContextBuilder 自动过滤孤立的 tool call 消息对，只保留有效的 HumanMessage
- **结果**: ✅ 通过

### 场景 2: Token 超限后的自动压缩
- **测试**: `test_compress_node_replaces_messages_after_context_overflow`
- **描述**: history 消息总 token 超过 `summary_trigger_tokens` 阈值
- **验证**: CompressNode 自动用 SystemMessage(摘要) 替换旧消息，保留尾部 N 条
- **结果**: ✅ 通过

### 场景 3: 知识图谱实体提取失败
- **测试**: `test_knowledge_graph_service_keeps_document_node_when_extraction_fails`
- **描述**: LLM 对文档返回空实体列表（提取失败）
- **验证**: 服务保留文档节点但不创建关系边，不抛异常
- **结果**: ✅ 通过

### 场景 4: eval 注入攻击
- **测试**: `test_calculate_rejects_unsafe_expression`
- **描述**: 用户输入 `__import__('os').system('rm -rf /')` 作为数学表达式
- **验证**: `calculate` 工具判定为不安全表达式并拒绝执行
- **结果**: ✅ 通过

### 场景 5: MCP 工具断连后本地回退
- **测试**: `test_llm_task_scheduler_invoke_chat_uses_local_fallback_without_redis`
- **描述**: Redis/MCP 服务不可用时，调度器自动回退到本地 SQLite 和内存队列
- **验证**: 即使没有外部基础设施，核心 Agent 调用仍能正常工作
- **结果**: ✅ 通过
